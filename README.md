# week-04-model-comparison-
Tested 4 AI models on 5 cybersecurity alert text samples to evaluate their suitability for the security alert classification component of our AI-powered security monitoring capstone project.

## Models Tested
- HF Sentiment (distilbert-sst-2)
- HF Zero-Shot (bart-large-mnli)
- HF NER (bert-large-NER)
- Groq Llama 3 8B

## Findings
Recommended Groq Llama 3 8B for the security alert classification component because it provided the most accurate severity classifications along with clear reasoning for each alert.
